BEFORE YOU RUN ANYTHING,
Maturin needs to be built. Therefore if you change any of the rust files, you need to:
1.
see if your venv is active (which python),
    if it shows /home/user/python_interpreter/bin/python3, activated
    if it shows /usr/bin/python3, not activated

if not activated,
    source /home/user/py311_venv/bin/activate (me only)

2. make sure maturin is installed
maturin -V
If it fails: pip install maturin

3.
You must run:
maturin develop --manifest-path vault_core/Cargo.toml
as your cargo.toml sits inside vault_core and maturin looks for a Cargo.toml in the directory its in.
